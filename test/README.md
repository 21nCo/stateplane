# Executable v1 contract fixtures

Run `npm test` (Node 20+, no package install required). `test/contract.test.js` exercises generic `entries` with synthetic values against `test/reference.js`. The reference is a deterministic synchronous contract oracle, **not** a SQL adapter, API server, secure production cursor implementation or evidence of deployed regional infrastructure. Its synthetic receipt timestamps/expiry are placeholders; retention is not chosen. It intentionally models only the tested subset (records, grants, compatible schema additions, simple keyset pages and projection rebuild); sources, claims, links, snapshots, real concurrency, indexed query plans and routing need downstream fixtures against real adapters. Do not ship this oracle as service code.

Explicit oracle limits: `define`/`revise` are uncredentialed setup helpers, so the suite does **not** prove `schema:write` authorization, lifecycle fencing or commit-time policy checks for schema operations (STA-7, with STA-6 for auth). The reference collection definition also has no collection enum-transition lifecycle rule: create/replace/patch transition checks, rule-change breaking revisions and concurrent commit enforcement are **normative but untested here**. STA-7 owns a rule-aware adapter and fixtures for permitted/forbidden transitions and rule revisions; the space-level `lifecycle` helper tests only space read/write availability, not collection transitions. The oracle accepts only unfiltered queries/counts/exists; any supplied filter fails `INVALID_ARGUMENT` instead of silently returning unfiltered results. Typed filters and filter-bound cursor digests require an adapter and fixtures from STA-8. The signed cursor models credential/space/collection/policy/schema and selected sort/position only; it does **not** model placement generation, actual expiry, secret rotation or multi-cell routing (STA-8 cursor/query adapter, with STA-6 placement/auth). Real adapters must add fixtures for these omissions; none relax the normative v1 contract.

Coverage: space isolation/revocation and independent per-collection grants (no wildcard), create-only/NFC/fixed-White_Space external keys and generated-ID namespace separation, collision-safe composite reservations with distinct per-collection constraint names and replacement release, null/missing and nullable enum checks, Unicode scalar validity for external keys and composite string data, valid UTC instant parsing/canonical uniqueness, immutable key input rejection, failure atomicity including event/receipt/outbox, mandatory revision with competing writers, declared-optional-only unset and valid absent-field no-op patches, lost committed response and old-revision replay across compatible schema additions with caller-supplied schema precondition, original-collection reauthorization before mismatch disclosure and UTF-8 ordered fingerprint keys, changed-payload rejection, tombstone key reservations, cursor scope/policy binding, creation-order keyset resume across ID width boundaries and optional scalar sort pages with missing/null/value partition and ID tie-breaking in both directions, unfiltered authoritative count/exists and fail-closed filtered calls, projection rebuild with exact-state preservation, closed-object and malformed-keyword schema rejection at every depth, codepoint string length, literal `description` field compatibility, top-level-only optional additions, immutable accepted definitions and space lifecycle rejection. The oracle uses synthetic monotonic creation timestamps only to model default `(createdAt,id)` ordering; it does not test real clock behavior. `ARCHITECTURE.md` and `contracts/v1.md` define the wider normative contract.

For a real repository conformance suite, preserve test names and expected outcomes while replacing the oracle with an adapter harness that creates disposable cells/spaces, drives async transactions, injects commit/response-loss and outbox failures, freezes time for retention/expiry, and checks SQL state after every failure. A passing in-memory test does not prove Postgres isolation, Hyperdrive cache behavior, auth race fencing, HTTP/MCP equivalence, Cloudflare delivery or snapshot export. Owners: STA-5 (transactions), STA-6 (auth/routing), STA-7/8 (schema/query), STA-12/14 (projections), STA-9/10/11 (transport/UI). Run with isolated test credentials and record real provider/region/version evidence separately.
